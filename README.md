**Pouya Sadeghi · Amu Pouya Parvaneh** — backend developer, competitive programmer, and the person who will probably write a library for that.

Years of competitive programming shaped my instinct for optimal architecture, heuristics and data
structures. At **Goldis** I build concurrent worker systems that keep thousands of products in sync
across marketplaces, alongside automated gold trading systems built around queues and workers. Custom ORM to squeeze
I/O? Enterprise wrapper around FastAPI? The job decides the tool — and if it does not exist, I write it.

I care about typed integration boundaries, explicit async lifetimes, and choosing data structures for the actual workload. That is where the contest habits meet production systems.
